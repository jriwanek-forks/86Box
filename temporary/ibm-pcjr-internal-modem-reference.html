IBM PCjr Internal Modem: Reference Notes

Implementation notes for 86Box’s separate PCjr character-device modem. The primary source is IBM’s PCjr Technical Reference, November 1983, Internal Modem section (printed pages 3-33 through 3-71).

Hardware identity: the IBM PCjr Internal Modem combines an INS8250A asynchronous communications element with a Smart 103 modem. It is a Bell 103/113 110/300 bit/s modem. It does not use the Hayes AT command language: its default command introducer is Ctrl-N (ASCII 0x0E), and only the first character of each command word is significant.

Command framing and serial behavior

  • A command line begins with the current command character, ends at carriage return, and can contain comma-separated commands. The introducer can be changed with NEW; its reset default is Ctrl-N.
  • Commands are intercepted within the host-to-modem stream and are not sent to the remote caller. Ordinary data is otherwise transparent. Sending the command character twice sends it as data.
  • The default line format is seven data bits, even parity, one stop bit; the default modem line rate is 300 bit/s. The selectable rates are 110 and 300 bit/s.
  • PCjr modem status messages include OK, CONNECTED, NO ANSWER, NO DIAL TONE, BUSY, UNSUCCESSFUL, and RING. LONG RESPONSE 1 requests terse result codes.

86Box transport and configuration

Select IBM PCjr Internal Modem as a COM character device. The optional phonebook is a text file with one mapping per line:

5551212 bbs.example.net:2323
5553434 192.0.2.20:23

Dial one of the mapped numbers with Ctrl-N, DIAL 5551212, then carriage return. Set an optional TCP listen port on the receiving emulator; answer with A or use COUNT with DTR asserted for auto-answer. This adapter is independent of the Hayes modem and does not attach an 86Box virtual NIC.
